Interfaccia PA
1. Tool analitico per migliorare l'analisi dei dati storici sugli incidenti
2. Tool predittivo per supportare le decisioni pubbliche per migliorare la sicurezza stradale
Tool analitico:
Mappa interattiva
indice di incidente per tratto stradale
Classifica delle strade più pericolose
Analisi dei fattori di rischio
Analisi delle cause associate
Tool predittivo:
Probabilità di accadimento incidente in un determinato tratto di strada per meteo, giorno della
settimana, fascia oraria
Definizione di misure per la riduzione del rischio
Possibilità di valutare l'effetto della misura sulla riduzione dell'indice di incidente

Sviluppi futuri
Integrazione con dati PA non ancora condivisi: dati traffico,
illuminazione, stato delle strade, interventi eseguiti sulla rete
stradale,,...
Miglioramento della qualità del dato raccolto in sede di
incidente: checklist per forze dell'ordine
Integrazione con dati da cittadini (democrazia partecipativa con
interfaccia cittadino): dati di incidenti con constatazione
amichevole, stato delle strade (buche, deterioramento del
manto stradale), incroci pericolosi,...

Vantaggi:
Efficacia: Decisioni oggettive guidate dai dati da parte di PA:
